⚠️ تشغيل الشبكة التلقائي AYHEM AUTO-LIVE ⚠️

لتشغيل كامل شبكة WOLF ULTRA + SENTIENT MASTER + لوحة التحكم الحية تلقائيًا:

💻 أمر التشغيل:
node ayhem_core/AYHEM_AUTO_LIVE.js

📌 هذا الأمر يقوم بالتالي:
1. تشغيل جميع خلايا WOLF ULTRA وSENTIENT MASTER.
2. التعلم الذاتي، التصحيح الفوري، وإنشاء خلايا جديدة عند الحاجة.
3. توليد تقارير الذاكرة والتنبؤات في الوقت الحقيقي.
4. تشغيل لوحة تحكم حية على المتصفح على الرابط: http://localhost:8080
5. التحديث المستمر تلقائيًا كل 15 ثانية.
