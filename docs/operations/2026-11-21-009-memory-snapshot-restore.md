## 5. الحدود

- اختبارات الاستعادة تستخدم adapter اختباري؛ لم يتم بعد اختبار IndexedDB في متصفح فعلي.
- IndexedDB تخزين محلي داخل المتصفح، وليس نسخة سحابية أو ضماناً ضد مسح بيانات المتصفح.
- لم تُرحّل بيانات `localStorage` القديمة، ولم يُوصل المخزن بعد بـ MemoryLink أو واجهة AI.
- لا يوجد حذف أو استبدال للسجلات في واجهة المخزن الجديدة.
