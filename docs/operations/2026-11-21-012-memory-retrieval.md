## ضمانات التصميم
- كل نتيجة تحمل السجل الأصلي ومصدره وحالته ونوعه وتاريخه ودرجة الثقة ومراجع supersedes.
- الترتيب حتمي: درجة التطابق ثم الثقة ثم التاريخ ثم المعرّف.
- لا تُنشأ حقائق أو استنتاجات جديدة؛ هذه طبقة lexical retrieval وليست بحثاً دلالياً أو تحققاً من الحقيقة.
- لا تعديل أو حذف أو ترحيل للذاكرة القديمة.
- لا اتصال شبكي ولا إرسال محتوى إلى AI.

## التحقق والقيود
- الاختبارات أضيفت إلى مجموعة Node الحالية وتعمل عبر مسار CI القائم.
- نتيجة CI ستسجل بعد تشغيل GitHub Actions على commit العملية.
- لا يزال اختبار IndexedDB في متصفح فعلي غير منجز، كما أن MemoryLink القديم لم يُربط بهذا المخزن؛ واجهته متزامنة بينما المخزن الجديد asynchronous.
- لا دمج ولا نشر إنتاجي.

## الخطوة التالية
بناء طبقة توافق async صريحة مع MemoryLink بعد توثيق كل المستهلكين الحاليين واختبار عدم تغيير السلوك القديم.
