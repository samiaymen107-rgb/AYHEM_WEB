# 🧠 الميثاق التشغيلي للمؤسس — مشروع AYHEM

> **«القيادة تُقاس بما يُبنى ويستمر، لا بما يُقال عن القائد.»**

هذا الدليل يحوّل الرؤية القيادية للمؤسس إلى قواعد عمل قابلة للتطبيق. مصطلح «السيغما» هنا استعارة ثقافية غير رسمية لوصف الاستقلالية والعمل العميق؛ **ليس تشخيصاً نفسياً ولا تصنيفاً علمياً معتمداً، ولا يجوز استخدامه للحكم على شخصية أي إنسان أو قدراته.**

---

## 1. هوية القيادة

| العنصر | المبدأ التشغيلي |
|:--|:--|
| الدور | المؤسس وصاحب الرؤية والقرار الاستراتيجي النهائي |
| المهمة | حماية رسالة AYHEM، تحديد الأولويات، ومراجعة النتائج |
| أسلوب العمل | استقلالية مسؤولة، عمل عميق، وتواصل موثق |
| معيار النجاح | قيمة المخرجات، سلامتها، قابليتها للصيانة، واحترامها للمستخدم |
| العلاقة بالفريق | ثقة متبادلة، وضوح المسؤوليات، ومحاسبة عادلة |

## 2. مبادئ العمل

1. **الاستقلالية مع المساءلة:** تنفذ كل وحدة مهامها ضمن نطاق موثق، وتُظهر ما أنجزته وما تعذر عليها.
2. **العمل غير المتزامن أولاً:** تُفضّل الوثائق والملخصات وسجل القرارات؛ ويُستخدم الاجتماع عندما يضيف قيمة حقيقية.
3. **التركيز دون عزلة:** تُحمى فترات العمل العميق مع إبقاء قنوات التصعيد والتعاون مفتوحة.
4. **المرونة دون فوضى:** تتغير الخطة عند ظهور دليل أفضل، مع تسجيل سبب التغيير وأثره.
5. **الاحترام دون عبادة شخصية:** لا يُعفى المؤسس أو أي عضو من المراجعة أو الاختبار أو المساءلة.
6. **الحقائق قبل الانطباعات:** تُفصل المعلومات الموثقة عن السياق والاستنتاج والفرضية وما يحتاج إلى تحقق.

## 3. هيكل الوحدات المستقلة

| الوحدة | مسؤوليتها | مخرجها |
|:--|:--|:--|
| MEMORY | حفظ السجلات والمصادر وسلامة الاستعادة | ذاكرة قابلة للتدقيق |
| COGNITION | تحليل العلاقات وإظهار الإشارات والاستنتاجات | نتائج مفسرة مع provenance |
| AUTONOMY | تخطيط المهام الآمنة وتنفيذها ضمن السياسة | سجل مهام ونتائج |
| GUARD | الحماية والصلاحيات والخصوصية والاختبارات | قرارات سماح/رفض موثقة |
| LINK | التكامل بين الواجهات والخدمات | عقود اتصال واختبارات توافق |

تتعاون الوحدات عبر واجهات وعقود معلنة، ولا تفترض إحداها صلاحيات الوحدة الأخرى.

## 4. حدود القرار والاستقلالية

### أعمال آمنة يمكن أتمتتها ضمن الصلاحيات الموجودة
- قراءة الملفات العامة وتحليلها.
- تنظيم الملاحظات والتوثيق وإعداد التقارير.
- تشغيل الاختبارات غير المدمرة.
- اقتراح تحسينات وإنشاء فروع تطوير وطلبات سحب.
- مراجعة نتائج CI وإصلاح الإخفاقات.
- دمج التغييرات الروتينية المفوضة بعد نجاح الفحوصات المطلوبة والمراجعة وعدم بقاء مخاطر جوهرية غير محلولة.

### أعمال تتطلب مراجعة أو موافقة المؤسس
- النشر الإنتاجي أو أي إجراء خارج نطاق التفويض الروتيني.
- حذف بيانات أو سجلات أو نسخ احتياطية.
- تغيير الصلاحيات أو سياسات الوصول.
- إنشاء أو كشف أو تدوير الأسرار ومفاتيح الخدمات.
- إرسال بيانات خاصة إلى خدمة خارجية.
- الإنفاق أو الالتزام المالي أو أي إجراء قانوني.

**لا تمنح AYHEM نفسه صلاحيات جديدة، ولا يغيّر السجل التاريخي بصمت.** التصحيح يكون بإضافة سجل جديد مرتبط بالأصل، مع إبقاء المصدر قابلاً للمراجعة.

## 5. حل الخلافات واتخاذ القرارات

1. تُكتب المسألة والحقائق المتاحة والخيارات والمخاطر.
2. يُفصل ما هو مثبت عما هو استنتاج أو افتراض.
3. تُمنح الأطراف فرصة مراجعة مستقلة عند الحاجة.
4. يُسجل القرار وصاحبه وأسبابه وتاريخه.
5. تُحدد نقطة مراجعة إذا ظهرت معلومات جديدة.

لا يُفرض فصل الأشخاص إلى أنماط نفسية، ولا يُفترض أن اجتماع شخصين مستقلين يؤدي حتماً إلى صراع. تُعالج الخلافات بحسب الوقائع والسلوك والحوكمة.

| المؤشر | طريقة القياس |
|:--|:--|

| سلامة الذاكرة | أخطاء الإحالات والتعارضات البنيوية المكتشفة |

| الاستقرار | عدد الإخفاقات المتكررة وزمن إصلاحها |
| الأمان | عدد الأسرار المكشوفة والإجراءات الحساسة غير المصرح بها |

لا تُستخدم الأرقام منفردة لتقييم الأشخاص؛ بل لتحديد مواضع تحسين النظام.

النسخة السابقة استخدمت «رجل السيغما» و«ألفا/بيتا» كأنها نماذج علمية في علم النفس التنظيمي. هذه المصطلحات ليست تصنيفاً نفسياً علمياً معتمداً، ولا يصح استنتاج صفات ثابتة أو قدرات أو مخاطر لشخص بناءً عليها. احتفظنا بالاستعارة الثقافية فقط، واستبدلنا الأحكام الشخصية بقواعد عمل قابلة للملاحظة والاختبار.
